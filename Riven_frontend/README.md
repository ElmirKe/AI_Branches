# Riven frontend

Визуальный branching-чат, который работает как статический сайт на GitHub Pages.
Браузер обращается к Gemini напрямую и показывает ответ частями по мере генерации.

## Запуск

```bash
npm install
npm run dev
```

После открытия сайта вставьте Gemini API key в поле слева. Ключ хранится только в
текущей вкладке браузера и не входит в production-сборку.

```bash
npm run build
```

Команда проверяет TypeScript и создаёт сборку в `dist/`. Инструкции по автоматической
публикации находятся в `../RUN.md`.

## Возможности

- streaming-ответы Gemini;
- отдельный контекст для каждой ветки;
- разложение списков на ветви;
- слияние веток;
- горизонтальная и вертикальная раскладка дерева;
- светлая и тёмная темы.
