# Форки

Визуальный чат с ИИ, где разговор — дерево, а не лента. Ответ ИИ приходит с backend
(см. `../RUN.md`), а если адрес backend не задан — сайт работает на заглушке. Разложение,
родословная и слияние веток работают в обоих режимах.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173.

`npm run build` — проверка типов и production-сборка в `dist/`.

## Подключение к backend

```bash
copy .env.example .env.local     # Windows (на Mac/Linux: cp)
```

В `.env.local` — `VITE_API_URL=http://localhost:8080`. Без этого файла работает заглушка.
Подробности запуска backend — в `../RUN.md`.

## Что можно попробовать

1. Задайте вопрос со словом «план» (или «шаги», «этапы», «варианты», «разбей») —
   ответ придёт списком, на карточке появится «Разложить (N)».
2. «Разложить» превращает каждый пункт в ветку-сестру. Сёстры собраны в семью
   с общей плашкой.
3. Откройте ветку — справа появится линейный чат только по родословной
   (от корня до этой точки). «Ответвить» создаёт новую ветку от узла.
4. «Свести» — выберите на холсте одну или несколько сестёр и подтвердите.
   Золотой узел-слияние встанет на место слитых веток; кнопка «Слитые (N)»
   на нём разворачивает их обратно для просмотра.
5. Узел-слияние — обычный узел: его можно сливать дальше с оставшимися
   сёстрами (каскад) и продолжать от него разговор.

## Структура

```
src/
  types.ts               модель данных
  store.tsx              React Context: деревья, выбранный узел, тема, режим слияния
  lib/api.ts             запрос ответа ИИ на backend (или заглушка) + детектор списка
  lib/layout.ts          индекс дерева, сёстры, родословная, раскладка координат
  components/            Sidebar, StartScreen, TreeCanvas, NodeCard, FamilyGroup,
                         BranchPanel, MergeMode
  styles.css             переменные тем и все стили
```
